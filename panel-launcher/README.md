# OpenFlux Panel Launcher for Windows

Компактный Windows companion-клиент для административного доступа к уже
развёрнутой веб-панели OpenFlux. Исходная версия приложения — **0.3.0**.
Лаунчер создаёт SSH port-forward к loopback панели и открывает её в браузере.
Он не является VPN-клиентом и не запускает VPN-ядро.

**Скачать:** [OpenFlux Panel Launcher 0.3.0 для Windows x64 (ZIP)](https://github.com/QA-E2E4/vpn-control-center/raw/refs/heads/main/downloads/OpenFluxPanelLauncher-0.3.0-Windows-x64.zip).
Внутри — лаунчер и документация. Настройки сервера и путь к вашему ключу
задаются локально при первом запуске; архив не содержит пользовательских
настроек или приватных ключей. Исполняемый файл не подписан Authenticode.

## Возможности

- Настраиваемые SSH host, port, user и путь к локальному приватному ключу.
- Использование штатного Windows OpenSSH `ssh.exe`, без командной оболочки.
- Локальный forward `127.0.0.1:8787` к loopback веб-панели на сервере.
- Проверка SSH-туннеля и ответа панели перед открытием браузера.
- Использование `known_hosts`; новый или изменившийся host key автоматически
  не принимается.
- Системный трей, состояния подключения, ручное отключение и SSH-журнал.
- Настройки хранятся локально для текущего пользователя Windows.

## Как работает

```text
Launcher → Windows OpenSSH → SSH local forward → localhost в браузере
                                             └→ панель на loopback VPS:8787
```

Лаунчер только открывает браузерный интерфейс управления. Он не меняет VPN-
профили, не импортирует ключи OpenFlux/Happ/Amnezia и не перенаправляет общий
интернет-трафик компьютера. Для VPN требуется отдельный совместимый клиент.

## Требования

- Windows 10/11 и компонент **OpenSSH Client**.
- .NET Framework 4.5+ для запуска.
- .NET Framework reference assemblies и `csc.exe` для сборки.
- Доступный SSH-сервер и панель на loopback-порту `8787` удалённой машины.
- Приватный SSH-ключ, разрешённый для выбранного серверного аккаунта.

Установка приложения и права администратора не нужны. Если ключ защищён
passphrase, заранее настройте Windows `ssh-agent`: лаунчер не сохраняет и не
запрашивает passphrase.

## Сборка и тесты

Из каталога `panel-launcher/source` в Windows Command Prompt:

```bat
build.cmd
```

Результат `OpenFlux.exe` появится в `panel-launcher/`. Бинарники не хранятся в
Git: собирайте их из исходников и проверяйте в соответствии с политиками
безопасности вашей организации.

Запустить 23 логические проверки:

```bat
test.cmd
```

Тесты используют временные фиктивные файлы ключей и зарезервированный
документационный IP-адрес. Они не подключаются к серверу и удаляют временные
данные по завершении. Проверяются валидация настроек, quoting аргументов,
обработка пути и сохранение настроек без записи содержимого ключа.

## Локальные настройки

Настройки текущей учётной записи Windows хранятся в:

```text
%LOCALAPPDATA%\OpenFluxPanel\settings.json
```

Файл содержит параметры SSH и **путь** к выбранному ключу, не содержимое
приватного ключа и не passphrase. Обычный путь к пользовательскому ключу:
`%USERPROFILE%\.ssh\id_ed25519`. Не публикуйте `settings.json`, ключи или
SSH-журналы: они могут раскрыть персональные пути, имя учётной записи и адрес
сервера.

После настройки нажмите «Подключиться». Окно может быть скрыто в системном
трее, пока SSH-туннель работает. Меню трея позволяет открыть панель, вернуться
к настройкам, отключить туннель или выйти. После перезапуска Windows
подключение запускают вручную; автозапуск и автоматическое переподключение
в версии 0.3.0 не реализованы. Выход закрывает SSH-процесс лаунчера, но не
останавливает серверные VPN-службы.

## Дополнительная утилита favicon

`tools/Update-Browser-Icon.cmd` и `tools/update-browser-icon.py` — отдельная
административная утилита. Она использует сохранённые SSH-параметры, обновляет
встроенный PNG favicon в `/opt/openflux-panel/static/index.html` и создаёт
резервную копию HTML-файла. Перед запуском проверьте выбранный сервер и код
утилиты. После обновления перезагрузите страницу панели с очисткой кэша.

## Происхождение версии

Исходники отражают версии 0.2.1 → 0.2.2 → 0.3.0: исправление совместимости с
.NET Framework при обработке путей; иконки EXE/окна/трея; затем обновлённый
интерфейс и карточка состояния. В репозитории сохранены C#-исходники, тесты,
manifest и исходные SVG/ICO/PNG-ресурсы. Персональные скриншоты, настройки и
собранный из личной конфигурации EXE не публикуются.

## Ограничения и безопасность

- Используется `StrictHostKeyChecking=yes`; первичный fingerprint сервера
  следует сверить с независимой консолью/панелью провайдера.
- SSH-forward слушает только loopback компьютера, не внешние интерфейсы.
- Соединение идёт непосредственно к настроенному SSH-серверу. Лаунчер не
  обходит ограничения мобильных сетей и не гарантирует доступность VPS.
- Зелёный индикатор означает, что SSH-туннель и веб-панель доступны; он не
  подтверждает VPN handshake или интернет через VPN.
- При аварийном завершении Windows процесс `ssh.exe` может потребовать
  отдельной проверки в диспетчере задач. Лаунчер не завершает посторонние
  процессы.

SSH-журнал хранится в памяти приложения и очищается при новой попытке.
Перед передачей журнала удалите адреса серверов и имена пользователей.
