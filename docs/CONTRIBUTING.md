# Участие в проекте

## Локальная разработка

```powershell
python -m pip install -r panel\requirements.txt
python -m unittest discover -s panel\tests -p "test_*.py" -v
node panel\tests\frontend.test.js
node --check panel\static\app.js
```

Для Windows Desktop смотрите `WINDOWS_APP.md`. Исправления UI upstream
приложения предпочтительно предлагать владельцам OpenFluxDesktop/shared, если
они не относятся к панели в этом репозитории.

## Изменения backend

- Используйте только synthetic credentials в тестах.
- Проверяйте ошибки и недоступность интеграции; UI не должен сообщать успех
  до подтверждения операции сервером.
- Не добавляйте автоматическую блокировку устройства по IP или количеству
  соединений.
- Сохраняйте накопительные счётчики при рестартах; не добавляйте время
  последнего обновления статистики в UI.
- Не расширяйте сетевую экспозицию панели.

## Внесение изменений

Работа через Pull Request не обязательна. Небольшие коммиты должны описывать
намерение. Перед публикацией проверьте diff и секреты. Сохраняйте авторство,
NOTICE и license headers чужих компонентов.
