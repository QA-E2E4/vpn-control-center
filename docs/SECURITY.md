# Безопасность

## Область доверия

Панель рассчитана на один административный хост и loopback-доступ через
SSH-туннель. Её web token не заменяет аутентификацию аккаунтов. Не открывайте
порт напрямую в Интернет и не встраивайте token в Windows/Desktop клиент.

Backend исполняет системные операции; права панели, systemd, Docker, Xray и
Amnezia должны быть минимальными и проверенными. Запускайте демо на localhost,
не подключая production данные.

## Секреты

- Не добавляйте `.env`, VPN-профили, QR, ключи, cookies, UUID, токены, дампы,
  необработанные логи и персональные данные в GitHub issues/PR.
- Храните service EnvironmentFile и credentials вне web root с минимальными
  правами доступа. `.env.example` содержит только placeholder значения.
- Перед публикацией проверьте и текущие файлы, и staged diff, и историю Git.
- Секрет, когда-либо попавший в публичный Git, следует отозвать/заменить;
  удаление из последнего коммита не делает его снова секретным.

## Сообщение об уязвимости

Не публикуйте рабочий эксплойт или секрет в открытом issue. Если в GitHub
репозитории доступны private vulnerability reports, используйте их; иначе
свяжитесь с владельцем проекта приватно. Включите затронутую версию,
предпосылки и безопасные шаги воспроизведения. Не прикладывайте реальные
VPN-конфиги и персональные журналы.
